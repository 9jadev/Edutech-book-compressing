# Laravel Agent Instructions

## Project Overview
This is a Laravel application.

## Coding Guidelines
- Inspect existing code before making changes.
- Follow Laravel conventions and best practices.
- Avoid modifying unrelated files.
- Validate inputs and handle exceptions properly.

## Logging
- Use Laravel's Log facade for application logs.
- Never log passwords, API keys, or sensitive user information.

## Testing
- Run relevant tests after making changes.
- Check for regressions.
- Summarize files created or modified.
